# veille_lorys.fr


Blog personnel de veille technologique, avec navigation par terminal.

## Stack
Spring Boot 4 · Java 25 · PostgreSQL · Next.js · shadcn/ui · Docker · Nginx

## Lancer en local
docker compose up -d                # PostgreSQL
cd backend && ./mvnw spring-boot:run   # API sur http://localhost:8080
